# Carpeta de imágenes

Aquí van las imágenes reales (fotos, no generadas por IA) que se usan en las páginas del sitio.

## Cómo subir una imagen

1. En GitHub, entra en esta carpeta (`img/`) dentro de la rama `main`.
2. Pulsa **Add file → Upload files** y arrastra la imagen.
3. Usa un nombre de archivo descriptivo, en minúsculas y sin espacios (por ejemplo `plato-alimentacion.png`).
4. Avisa con el nombre exacto del archivo para integrarla en la página correspondiente.

Formatos recomendados: `.jpg`, `.png` o `.webp`.
